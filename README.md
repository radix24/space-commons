# Space Commons

땅에서 올려다보고, 우주로 나아가는 모두의 하늘. 브라우저에서 바로 여는 플라네타리움이자 태양계 비행 서비스입니다.

- 서비스: https://radix24.github.io/space-commons/
- 현재 버전: Alpha 0.0.1d
- 브랜드: [BRAND.md](BRAND.md) · [브랜드 시트](https://radix24.github.io/space-commons/brand.html)

## 기능 명세

### 1. 두 가지 보기 모드
| 모드 | 내용 |
|---|---|
| 지상 | 정한 장소와 시각에서 올려다본 하늘. 지면과 언덕·나무 실루엣이 지평선 아래를 가립니다. |
| 우주 | 태양계 안을 자유롭게 비행. 천체 주위를 돌거나 W A S D / Q E로 이동하고, Shift로 가속합니다. 수 m부터 수십억 km까지 한 화면에 그립니다. |

### 5. 관측 도우미
- 오늘의 천문 정보: 일출·일몰, 박명, 월출·월몰, 달의 위상, 관측하기 좋은 시간, 활동 중인 유성우
- 천문 달력: 앞으로 90일의 달 위상, 절기, 행성의 충과 최대 이각, 근접, 유성우 극대, 일식·월식. 누르면 그 순간으로 이동
- 일식·월식: 2026~2035년 일식·월식으로 이동, 관측 위치에 따른 일식, 지구 그림자에 들어간 붉은 달
- 지금 하늘: 지금 보이는 행성과 밝은 메시에 천체 목록
- 관측 목록: 보고 싶은 천체를 담고 관측 여부와 메모를 기록 (이 브라우저에 저장)
- 장비 시야: 쌍안경과 망원경 6가지의 실제 시야를 원으로 표시
- 광공해 단계: 보틀 척도 1~9에 따른 한계 등급과 은하수 밝기
- 대기 효과: 지평선 근처의 굴절과 소광(어두워지고 붉어짐)
- 낮 하늘: 낮에도 별 보기 / 파란 하늘과 별 / 실제 낮 하늘 중 선택. 해 질 녘 노을과 박명 표현
- 야간 시야: 어둠에 적응한 눈을 지키는 붉은 화면

### 6. 배우기와 공유
- 주제별 투어 6개: 하이라이트, 태양계 한 바퀴, 겨울 밤하늘, 외계행성, 탐사선의 역사, 은하와 성운
- 선택한 천체의 위키백과 요약과 사진 (한국어 우선)
- 두 천체 사이의 각거리
- 지금 보는 화면을 그대로 여는 공유 링크, 화면 캡처, 전체 화면

### 7. 사용 환경
- 데스크톱과 휴대폰 (휴대폰은 접히는 패널, 터치 조작, 휴대폰을 하늘에 비추는 기능)
- 홈 화면에 설치하는 앱, 한 번 연 뒤에는 인터넷 없이 실행
- 단축키: F 전체 화면, P 캡처, N 야간 시야, T 지금 하늘, Y 오늘 천문, O 관측 목록

## 자료 갱신
| 스크립트 | 갱신하는 자료 |
|---|---|
| `tools/fetch_probes.py` | 심우주 탐사선 궤도 (`data/probes.json`) |
| `tools/fetch_moons_flybys.py` | 추가 위성, 명장면 궤도 (`data/moons.json`, `data/flybys.json`) |
| `tools/fetch_korea_orbiters.py` | 한국 위성 궤도, 달·화성 궤도선 (`data/korea.tle`, `data/orbiters.json`) |
| `tools/fetch_exoplanets.py` | 외계행성 (`data/exoplanets.json`) |

## 버전 기록
기능 묶음 하나를 마칠 때마다 마지막 글자를 올립니다 (`app.js`의 `VERSION`).
- Alpha 0.0.1a: 지상·우주 모드, 탐사선, 외계행성, 실제 밝기
- Alpha 0.0.1b: 대기 굴절·소광, 광공해 단계, 달 지구조, 오늘의 천문 정보, 유성우, 관측 목록, 주제별 투어, 휴대폰 화면·하늘 비추기, 낮 하늘 3가지 보기
- Alpha 0.0.1c: 실제 하늘색, 일식·월식, 천문 달력, ISS·밝은 인공위성과 통과 예보, 탐사선 명장면, 위성 14개, 별자리 한국어 이름·경계, 설치형 앱
- Alpha 0.0.1d: 한국 인공위성 68기, 달·화성 궤도선 10기(다누리 포함), 달·화성·금성·수성 착륙 지점 32곳과 착륙선 모형, 행성 실제 자전 각도
