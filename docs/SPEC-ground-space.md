# Space Commons 지상·우주 모드 고도화 명세 (승인 대기)

기준 버전: Alpha 0.0.2b. 아직 개발하지 않은 기획안입니다. 번호로 승인·보류·삭제를 표시해 주세요.
규모: S = 하루 이하, M = 2~3일, L = 일주일 안팎.
이미 만든 기능은 빼고, 지난 명세에서 미뤄 둔 항목은 다시 넣었습니다.

## 지상 모드 (15개)

### 하늘을 더 실제처럼
| # | 기능 | 내용 | 자료·기술 | 규모 |

| G3 | 별의 반짝임 | 지평선에 가까울수록, 시상이 나쁠수록 별이 반짝입니다. 끌 수 있습니다. | 신틸레이션 모델 | S |

## 확인이 필요한 결정
1. 외부 실시간 자료(날씨, 오로라, 새 혜성)는 사이트가 직접 받아 올지, 매일 자동으로 받아 저장해 둘지
2. 고해상도 사진·지형(G1, S5)은 데이터가 크므로, 휴대폰에서는 낮은 품질로 자동 전환할지
3. 별자리 그림(G7)은 공개 그림을 쓸지, Space Commons 스타일로 새로 그릴지
