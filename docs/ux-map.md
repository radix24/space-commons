# UX 지도: 지상·우주 탭과 공통 메뉴

원칙: "똑똑한 사람의 우주"가 아니라 "모두의 우주". 이름은 열두 살이 읽어도 바로 알 수 있는 동사구로 짓는다. 위쪽 막대에는 한 번에 다섯 개 이하만 둔다. 나머지는 한 단계 아래에 넣고, 메뉴 안에서 바로 한 줄 설명을 붙인다. 안내(튜토리얼)는 원할 때만 연다.

## 2. 새 묶음: 할 일 중심

위쪽 막대 (한 번에 다섯 개):

1. **나는 처음이에요**: 가장 재미있는 세 가지(지금 하늘, 달·목성 찾기, 토성으로 날아가기)를 차례로 해 보는 단추
2. **오늘 밤 볼 것** (지상) / **우주로 날아가기** (우주)
3. **쉽게 알아보기**
4. **친구·학생과 나누기**
5. **설정·더 보기**

검색과 지상/우주/샌드박스는 항상 보이는 기본 틀로 둔다. 각 메뉴 항목 아래에는 한 줄 설명이 늘 보인다(마우스를 올리지 않아도).

| 메뉴 | 들어 있는 것 (새 이름) |
|---|---|
| 오늘 밤 볼 것 | 지금 보이는 것 · 해와 달 뜨는 시각 · 곧 일어날 하늘 일 · 내가 고른 천체 · 휴대폰으로 하늘 비추기 · 카메라 화면에 이름 겹치기 · 붉은 화면 (밤눈 지키기) · 별 궤적 사진 찍어 보기 |
| 우주로 날아가기 | 행성 차례로 둘러보기 · 탐사선이 지나간 순간 (+ 아래 패널의 기본 시점 · 지구로 · 태양으로 · 자유 비행) |
| 쉽게 알아보기 | 사용법 따라 하기 · 개념 카드로 알아보기 · 유명한 천체 구경 · 크기 비교하기 · 우리 조상의 하늘 |
| 친구·학생과 나누기 | 지금 화면 링크 복사 · 사진으로 저장 · 영상으로 녹화 · 수업 링크 만들기 · 나만의 발표 만들기 · 발표 파일 열기 |
| 설정·더 보기 | EN/한국어 · 화면 가득 보기 · 인터넷 없이 쓰기 |

아래 패널은 늘 쓰는 것(시간, 장소, 지면·대기·은하수·별자리선·이름·궤도)만 보이고 나머지는 "더 많은 표시 설정" 안에 접혀 있다(이전 작업 그대로). 모든 단추와 칸에는 마우스를 올리거나 길게 누르면 쉬운 말 한 문장 설명 상자가 뜬다.

사라진 기능은 없다. 모든 id와 동작은 그대로이고 위치와 이름만 바뀌었다.

## 4. 안내 (튜토리얼)

"쉽게 알아보기 → 사용법 따라 하기"(또는 화면 아래 도움말 줄 두 번 누르기)에서 고른다. 각 안내는 3~5단계이고 실제 단추를 파란 테두리로 짚는다.

- 나는 처음이에요: 지금 밤하늘 → 달 찾기 → 목성 찾기 → 토성으로 날아가기
- 하늘 둘러보기: 끌기 → 크게 보기 → 눌러서 알아보기 → 보이는 것 고르기
- 천체 찾기: 이름으로 찾기 → 지금 보이는 것 → 설명 읽기
- 우주 여행: 우주로 나가기 → 지구로·태양으로 → 기본 시점 → 자유 비행
- 시간 바꾸기: 빨리 돌리기 → 시간 끌기 → 날짜 고르기 → 지금으로

저절로 시작하지 않는다. 첫 방문에 왼쪽 위에 작은 알림 하나만 뜨고, 닫으면 다시 안 뜬다.

## 5. 정보창

처음에는 중요한 사실 2~4개(설명, 거리, 크기, 밝기)만 쉬운 말로 보인다. 전체 표는 "자세히 보기" 안에 있고, 적경·적위·등급·이심률 같은 용어마다 한 줄 풀이가 붙는다(예: 적경 = 하늘의 경도 같은 좌표).
